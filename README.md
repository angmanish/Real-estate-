# Real-estate- | Dwello & Amaya Estates — Luxury Real Estate Platform

India's foremost private advisory for trophy residential assets. Preserving modern architectural pedigree, sacred Vastu Shastra purity, and multi-generational family sovereignty.

A high-fidelity modern luxury real estate landing page and multi-page web platform built with **Next.js 15 (App Router)**, **Tailwind CSS v4**, **TypeScript**, **Framer Motion**, and **Three.js**.

Designed in a clean, elegant light theme featuring warm cream and off-white tones (`#FAF7F2`), contrasting deep espresso brown typography and accents (`#231812`), authentic realistic luxury villa architecture, and a floating horizontal search and filter widget.

---

## 🌟 Key Features

- **Realistic Architectural Showcase**: Authentic high-resolution luxury estate photography featuring panoramic floor-to-ceiling glass, warm glowing interior lights, and lap pools.
- **Interactive 3D Spatial Walkthrough**: Built-in Three.js WebGL spatial model with orbit controls and customizable lighting modes.
- **Floating Horizontal Search Widget**: Elevated filter widget with soft drop shadows and rounded corners (Location, Residence Typology, Price Range).
- **Curated Bento Grid Portfolio**: Trophy estates across Mumbai (Worli Sea Face), Delhi NCR (Golf Course Road), Goa (Assagao), Bengaluru (Sadashivanagar), and Alibaug.
- **Sovereign Market Intelligence**: Institutional analytics module featuring real-time property index data and 5-year appreciation metrics.
- **Comprehensive Multi-Page Architecture**:
  - `/` — Main Hero, Bento Grid, Architectural Specs, Senior Advisory Profiles.
  - `/properties` — Advanced search, filter, and sorting catalog.
  - `/properties/[id]` — Dynamic luxury residence showcase with Vastu Shastra audit scores and RERA verification.
  - `/nri-services` — FEMA compliance, RBI repatriation, and overseas advisory liaison desks.
  - `/about` — The 5 Pillars of Amaya Trust and quarter-century heritage.
  - `/contact` — Confidential advisory briefing and direct WhatsApp desk.
- **VIP Inspection Scheduler**: Chauffeured transit preferences (Mercedes S-Class, Speedboat, Helipad access) and strict non-disclosure representation.

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or later
- npm, pnpm, or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/angmanish/Real-estate-.git

# Navigate to the project directory
cd Real-estate-

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the platform.

### Production Build
```bash
npm run build
npm run start
```
